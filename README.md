# مواهب داري - منصة دور الشباب في الجزائر 🌟

منصة رقمية موجهة لشباب الجزائر، تربطهم بدور الشباب وبيوت الشباب ومرافق الشباب في كل ولايات الوطن: دليل المرافق، الحجز المسبق، الفعاليات، النوادي والتطوع.

**إعداد: آية عابر**

## ✨ المميزات

### 🏠 دور ومرافق الشباب
- دليل لدور الشباب، بيوت الشباب، مخيمات الشباب والمركبات الرياضية الجوارية
- خريطة تفاعلية بعلامات ملونة حسب نوع المرفق
- بحث بالاسم أو البلدية أو النادي، مع تصفية حسب النوع والولاية (الولايات الـ58)
- «الأقرب إليّ» حسب موقعك، و«مفتوح الآن» حسب أوقات العمل
- قائمة المفضلة (تُحفظ على الجهاز)
- صفحة تفاصيل لكل مرفق: أوقات العمل، الهاتف، المرافق والخدمات، النوادي، الفعاليات القادمة، الاتجاهات عبر خرائط Google والمشاركة

### 🛏️ الحجز المسبق في بيوت الشباب والمخيمات
- التحقق من الأسرّة المتاحة حسب التواريخ وعدد الأشخاص
- حساب المبلغ التقديري (عدد الليالي × عدد الأشخاص × سعر الليلة)
- طلب حجز يتضمن نوع الإقامة والفئة وسبب الإقامة
- تذكرة حجز برمز QR ورمز حجز (مثل `MD-7KQ2PX`) قابلة للطباعة والمشاركة
- قائمة «حجوزاتي» مع حالة كل حجز وإمكانية الإلغاء

### 📅 فعاليات دور الشباب
- تصنيفات: ثقافي، رياضي، علمي وتقني، فني، ترفيه ورحلات، تطوعي
- عرض كقائمة أو تقويم شهري
- تصفية حسب دار الشباب
- زر «سأحضر» وعدد الحاضرين
- إضافة الموعد إلى تقويم الهاتف (ملف ‎.ics مع تذكير)
- ربط الفعالية بدار شباب عند إنشائها

### 🎭 النوادي والورشات
- دليل للنوادي في كل دور الشباب
- طلب انخراط (السن، المستوى، الهاتف) ومتابعة حالته من الملف الشخصي

### 🛠️ لوحة المدير
- مراجعة طلبات الحجز والانخراط: تأكيد أو رفض مع ذكر السبب، وإشعار تلقائي للمستخدم
- إحصائيات: الحجوزات الجديدة، المؤكدة، نزلاء اليوم، الانخراطات الجديدة
- تنبيه عند تجاوز سعة المرفق
- إضافة مرفق أو تعديله: البلدية، الهاتف، أوقات العمل، يوم الغلق، المرافق، النوادي، السعة وسعر الليلة

### 👀 تصفح دون حساب
- زر «تصفح المنصة كزائر» في شاشة الترحيب يفتح المنصة مباشرة (مناسب للجان التحكيم والزوار)
- التسجيل يُطلب فقط عند الحجز أو الانخراط أو التطوع أو اقتراح فعالية
- فعاليات ومرافق نموذجية بعلامة «نموذج» ما دامت قاعدة البيانات فارغة

### 📱 على الهاتف والحاسوب
- تصميم للهاتف بشريط تنقل سفلي، وللحاسوب بشريط جانبي ومحتوى على عمودين
- يمكن إضافة المنصة إلى الشاشة الرئيسية للهاتف كتطبيق (ملف `manifest.webmanifest` وأيقونات `icons/`)
- صورة معاينة عند مشاركة الرابط على واتساب وفيسبوك

### ومن قبل
- تسجيل دخول وإنشاء حساب للمتطوعين والمدراء
- فعاليات التطوع والموافقة عليها، نظام النقاط ولوحة الشرف، معرض الصور، الإشعارات، الوضع الفاتح

## 📌 البيانات النموذجية
ما دامت قاعدة البيانات لا تحتوي على أي مرفق شباب، تعرض المنصة مرافق نموذجية في عشر ولايات، من الجزائر العاصمة إلى تمنراست (بعلامة «نموذج») لتوضيح طريقة العمل. أسماؤها وإحداثياتها تقريبية، ولا تحمل أرقام هواتف.
تختفي هذه المرافق تلقائياً فور إضافة أول مرفق حقيقي. يمكن للمدير فتح أي مرفق نموذجي، تصحيح معلوماته، ثم الضغط على «حفظ كمرفق حقيقي».

## 🔥 Firebase (Realtime Database)
العُقد المستعملة:

| العقدة | المحتوى |
|---|---|
| `users`, `events`, `places`, `photos`, `notifications` | كما في السابق |
| `places/{id}` | حقول إضافية لمرافق الشباب: `commune`, `phone`, `email`, `openTime`, `closeTime`, `closedDay`, `facilities`, `clubs`, `capacity`, `price` |
| `events/{id}/attendees/{uid}` | المستخدمون الذين سجلوا حضورهم |
| `bookings/{id}` | طلبات الحجز (يقرؤها المدير، ويقرأ كل مستخدم حجوزاته عبر `orderByChild('userId')`) |
| `occupancy/{placeId}/{bookingId}` | التواريخ وعدد الأشخاص فقط، بدون معلومات شخصية، لحساب الأسرّة المتاحة |
| `memberships/{id}` | طلبات الانخراط في النوادي |

## 🔒 الأمان وصلاحيات المدير
- كل حساب جديد يُنشأ **كمتطوع**. من يختار «مدير» عند التسجيل يُسجَّل له طلب (`adminRequest`) يظهر للمدراء في **الإعدادات ← إدارة المستخدمين**، ومن هناك يُقبل أو يُرفض. يمكن أيضاً ترقية أي متطوع أو سحب الصلاحية من مدير آخر.
- الحماية الفعلية تأتي من قواعد الأمان في الملف [`database.rules.json`](database.rules.json)، لأن واجهة الموقع وحدها لا تمنع من يكتب في قاعدة البيانات مباشرة. هذه القواعد:
  - تمنع أي مستخدم من جعل نفسه مديراً، وتسمح للمدير فقط بتغيير الأدوار
  - تجعل إضافة المرافق وقبول الفعاليات وتأكيد الحجوزات والانخراطات خاصة بالمدير
  - تسمح لكل مستخدم بقراءة حجوزاته وانخراطاته وإشعاراته فقط، وإلغاء حجوزاته فقط
  - تجعل `places` (دليل المرافق) قابلة للقراءة للجميع

### نشر القواعد (مرة واحدة)
1. افتح [Firebase Console](https://console.firebase.google.com/) ← مشروع **mawaheb-dari** ← **Realtime Database** ← تبويب **Rules**
2. احفظ نسخة من القواعد الحالية (انسخها في ملف) تحسباً للرجوع إليها
3. الصق محتوى `database.rules.json` كاملاً، ويمكنك تجربته أولاً من **Rules Playground**
4. اضغط **Publish**

> إذا لم يكن لديك أي حساب مدير بعد: افتح تبويب **Data** في Realtime Database ← `users` ← حسابك، وغيّر قيمة `role` إلى `admin` يدوياً، ثم أعد فتح الموقع.

## 📱 كيفية الاستخدام
1. اختر نوع المستخدم (متطوع أو مدير)
2. سجل دخول أو أنشئ حساباً جديداً
3. اكتشف دور الشباب القريبة منك من تبويب «دور الشباب»
4. احجز إقامتك من تبويب «الحجز» واحتفظ بالتذكرة
5. تابع الفعاليات وسجّل حضورك، وانخرط في النوادي
6. تطوع واكسب النقاط وتنافس مع الآخرين
