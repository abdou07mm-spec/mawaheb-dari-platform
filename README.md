# مواهب داري - منصة شباب سطيف الذهبي 🌟

منصة تفاعلية تربط الشباب بدور الشباب وبيوت الشباب والمساجد في ولاية سطيف: دليل المرافق، الحجز المسبق، الفعاليات، النوادي والتطوع.

## ✨ المميزات

### 🏠 دور ومرافق الشباب
- دليل لدور الشباب، بيوت الشباب، مخيمات الشباب والمركبات الرياضية الجوارية
- خريطة تفاعلية بعلامات ملونة حسب نوع المرفق
- بحث بالاسم أو البلدية أو النادي، مع تصفية حسب النوع
- «الأقرب إليّ» حسب موقعك، و«مفتوح الآن» حسب أوقات العمل
- قائمة المفضلة (تُحفظ على الجهاز)
- صفحة تفاصيل لكل مرفق: أوقات العمل، الهاتف، المرافق والخدمات، النوادي، الفعاليات القادمة، الاتجاهات عبر خرائط Google والمشاركة

### 🛏️ الحجز المسبق في بيوت الشباب والمخيمات
- التحقق من الأسرّة المتاحة حسب التواريخ وعدد الأشخاص
- حساب المبلغ التقديري (عدد الليالي × عدد الأشخاص × سعر الليلة)
- طلب حجز يتضمن نوع الإقامة والفئة وسبب الإقامة
- تذكرة حجز برمز QR ورمز حجز (مثل `MD-7KQ2PX`) قابلة للطباعة والمشاركة
- قائمة «حجوزاتي» مع حالة كل حجز وإمكانية الإلغاء

### 📅 فعاليات دور الشباب
- تصنيفات: ثقافي، رياضي، علمي وتقني، فني، ترفيه ورحلات، تطوعي
- عرض كقائمة أو تقويم شهري
- تصفية حسب دار الشباب
- زر «سأحضر» وعدد الحاضرين
- إضافة الموعد إلى تقويم الهاتف (ملف ‎.ics مع تذكير)
- ربط الفعالية بدار شباب عند إنشائها

### 🎭 النوادي والورشات
- دليل للنوادي في كل دور الشباب
- طلب انخراط (السن، المستوى، الهاتف) ومتابعة حالته من الملف الشخصي

### 🛠️ لوحة المدير
- مراجعة طلبات الحجز والانخراط: تأكيد أو رفض مع ذكر السبب، وإشعار تلقائي للمستخدم
- إحصائيات: الحجوزات الجديدة، المؤكدة، نزلاء اليوم، الانخراطات الجديدة
- تنبيه عند تجاوز سعة المرفق
- إضافة مرفق أو تعديله: البلدية، الهاتف، أوقات العمل، يوم الغلق، المرافق، النوادي، السعة وسعر الليلة

### ومن قبل
- تسجيل دخول وإنشاء حساب للمتطوعين والمدراء
- فعاليات التطوع والموافقة عليها، نظام النقاط ولوحة الشرف، معرض الصور، الإشعارات، الوضع الفاتح

## 📌 البيانات النموذجية
ما دامت قاعدة البيانات لا تحتوي على أي مرفق شباب، تعرض المنصة مرافق نموذجية في ولاية سطيف (بعلامة «نموذج») لتوضيح طريقة العمل. أسماؤها وإحداثياتها تقريبية، ولا تحمل أرقام هواتف.
تختفي هذه المرافق تلقائياً فور إضافة أول مرفق حقيقي. يمكن للمدير فتح أي مرفق نموذجي، تصحيح معلوماته، ثم الضغط على «حفظ كمرفق حقيقي».

## 🔥 Firebase (Realtime Database)
العُقد المستعملة:

| العقدة | المحتوى |
|---|---|
| `users`, `events`, `places`, `photos`, `notifications` | كما في السابق |
| `places/{id}` | حقول إضافية لمرافق الشباب: `commune`, `phone`, `email`, `openTime`, `closeTime`, `closedDay`, `facilities`, `clubs`, `capacity`, `price` |
| `events/{id}/attendees/{uid}` | المستخدمون الذين سجلوا حضورهم |
| `bookings/{id}` | طلبات الحجز (يقرؤها المدير، ويقرأ كل مستخدم حجوزاته عبر `orderByChild('userId')`) |
| `occupancy/{placeId}/{bookingId}` | التواريخ وعدد الأشخاص فقط، بدون معلومات شخصية، لحساب الأسرّة المتاحة |
| `memberships/{id}` | طلبات الانخراط في النوادي |

> ⚠️ إذا كانت قواعد الأمان (Rules) تحدد العقد المسموح بها، أضف إليها `bookings` و`occupancy` و`memberships`، مع فهرس `".indexOn": ["userId"]` على `bookings` و`memberships`.

## 🚀 تقنيات المشروع
- HTML5 / CSS3 / JavaScript (ملف واحد `index.html`)
- Firebase (Auth, Realtime Database, Storage)
- Leaflet + OpenStreetMap للخرائط
- qrcodejs لرموز QR
- Font Awesome و Google Fonts (Tajawal)

## 📱 كيفية الاستخدام
1. اختر نوع المستخدم (متطوع أو مدير)
2. سجل دخول أو أنشئ حساباً جديداً
3. اكتشف دور الشباب القريبة منك من تبويب «دور الشباب»
4. احجز إقامتك من تبويب «الحجز» واحتفظ بالتذكرة
5. تابع الفعاليات وسجّل حضورك، وانخرط في النوادي
6. تطوع واكسب النقاط وتنافس مع الآخرين
